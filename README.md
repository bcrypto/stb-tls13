# The STB-TLS13 Internet Draft

## What is STB-TLS13?

STB-TLS13 is an Internet draft that introduces a subset of STB (STandards of 
Belarus) cryptographic algorithms and defines their use in TLS 1.3. The 
document is self-contained, i.e., it fully describes the required STB 
algorithms. It can be used to develop STB-compliant TLS 1.3 implementations 
without referring to the original STB standards.
